写真から土壁の面積を出したい場合

結論：できます。ただし、写真だけでは実寸の㎡は確定できないことが多いです。基準となる長さが写真内に必要です。
  • できる条件：メジャー、定規、既知サイズのブロック、窓枠寸法、レーザー距離計の値など、実寸の基準が1つ以上ある。
  • かなり正確にできる条件：壁を正面に近い角度で撮影、四隅が見える、基準長さが同じ平面上にある。
  • 難しい条件：斜め撮影、魚眼気味、壁の一部が隠れる、基準物がない、遠近で大きく歪む。
  • おすすめ手順：①写真から土壁部分をAIで抽出 → ②写真上で基準長さを指定 → ③四隅または多角形点を打つ → ④㎡/坪を算出。
次の段階としては、「写真を読み込んで土壁だけをなぞる → 基準長さ1本を入れる → 面積を出す」専用ツールは作れます。 ただし、写真フォルダを勝手に巡回して自動取得はこのチャットだけではできません。写真をまとめてアップロードしてもらえれば、その範囲で選別や設計はできます。

写真から土壁の面積を出す（スマホ現場向け）

目的：この機能は 「実際に土壁を塗る面積」 を出すためのものです。
部屋ごとに管理し、その中に 壁 を追加します。各壁には 写真1〜4枚 登録できます。各写真では ①基準線を2点 → ②実寸を入力 → ③塗る土壁だけを囲う だけです。
大事なルール：重なって写る土壁は どちらか片方の写真だけ で囲ってください。塗る場所だけ を囲います。
保存について
  • このアプリは A4縦のJPEGを必要ページ分 作れます。
  • 端末の写真フォルダへ完全自動保存 はブラウザや端末仕様で制限されることがあります。
  • そのため、JPEGを作成 → ダウンロード / 共有 の形にしています。スマホ側で写真保存しやすいようにしてあります。
